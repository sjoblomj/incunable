Miscellaneous

Commonmark features are supported, such as inlining code and commands like this: grep -Irin searchstring.

The GitHub flavour of Commonmark is used, meaning it has support for extensions like tables and Strikethrough.1

Code blocks

Code blocks can be inserted as follows. The syntax highlighting from GlyphDrawing.Club is applied by the font itself, and the colours can be customized in the CSS. It is not perfect, but it is neat. The line numbering is applied by the CSS.

{{begincode}}
function add(a, b) {
  return a + b;
}
console.log(add(1, 2));
{{endcode}}


function add(a, b) {
  return a + b;
}
console.log(add(1, 2));

Templates within templates

There is support for adding templates within templates, like this, where a line break is inserted in the description:

{{imgframe |ref=rider |file=rider.jpg |title=Horses of yore.{{linebreak}}From the book Bibliotheca Spenceriana; or, A descriptive catalogue of the library of George John, earl Spencer.}}
